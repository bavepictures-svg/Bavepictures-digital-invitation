Après chaque génération, ajouter une entrée dans admin/clients.js (même commit que le dossier du client) :

{
  slug: "aline-marc",            // nom du dossier dans clients/
  name: "Aline & Marc",          // nom affiché
  theme: "ivory-botanical-gold", // ivory-gold | ivory-botanical-gold
  languages: ["fr", "en"],       // ["fr"] | ["en"] | ["fr", "en"]
  created: "2026-11-19",         // AAAA-MM-JJ
},
  • Le lien public est construit automatiquement : baseUrl + clients/<slug>/.
  • Un thème inconnu de cette page s'affiche avec son identifiant tel quel.
